# Personal Journal Manager

## Project Description

The Personal Journal Manager is a Python-based project that allows users to manage their personal journal entries using file handling and object-oriented programming (OOP).

Users can add new entries, view all entries, search entries using a keyword or date, and delete all entries.

## Features

* Add a New Journal Entry
* View All Journal Entries
* Search Entries by Keyword or Date
* Delete All Entries with Confirmation
* Store entries with date and time
* Handle file-related exceptions
* Menu-driven program

## Technologies Used

* Python
* File Handling
* Object-Oriented Programming (OOP)
* Exception Handling
* `datetime` Module
* `os` Module

## File Modes Used

| Mode | Purpose                 |
| ---- | ----------------------- |
| `x`  | Create a new file       |
| `a`  | Add entries to the file |
| `r`  | Read journal entries    |
| `w`  | Clear the file contents |

## Exception Handling

The project handles the following exceptions:

* `FileNotFoundError`
* `FileExistsError`
* `PermissionError`
* `OSError`

## Project Menu

1. Add a New Entry
2. View All Entries
3. Search for an Entry
4. Delete All Entries
5. Exit
